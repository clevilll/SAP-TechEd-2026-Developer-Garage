# Dataset — SAP TechEd 2026 AI Track

This folder contains the sample shipment data used in the **SAP TechEd 2026 — TabPFN-3.5 Plus on SAP AI Core** tutorial.

The original `payload_data.py` file is maintained in SAP's official GitHub repository:

**[View the original payload_data.py](https://github.com/sap-tutorials/Tutorials/blob/master/tutorials/ai-core-prior-labs-langgraph/payload_data.py)**

The file provides:
- `payload`: Shipment records for regression (`DELAY_DAYS`) and classification (`LATE`).
- `GROUND_TRUTH`: Actual target values for evaluating predictions.

**Source:** [SAP Developer Tutorial — Add Prior Labs TabPFN-3.5 Plus on SAP AI Core to Your AI Agent](https://developers.sap.com/tutorials/ai-core-prior-labs-langgraph)
